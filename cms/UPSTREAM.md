# Origem

Adaptado do template oficial Payload `templates/with-vercel-website`, tag v3.92.0,
commit e6f7db8b71facd9ee5ef67feb3b065b2684370d2.

https://github.com/payloadcms/payload/tree/v3.92.0/templates/with-vercel-website

A licença MIT original está em `LICENSE.payload`. As rotas de administração/API
e o layout do Payload foram preservados. O frontend foi reduzido para este blog;
coleções adaptadas para um autor, SQLite/Turso, Lexical e Blob. Páginas e usuários
de demonstração, formulários, busca e agendamento do template foram omitidos.
As dependências Payload estão alinhadas em 3.92.0; a tag do template ainda apontava
3.90.0 no package.json, atualizada aqui para a própria versão estável da tag.
